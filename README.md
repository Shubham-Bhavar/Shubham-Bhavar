## 🤖 Featured Project — Orchestrate 2026: "Buy or Wait?"

<div align="center">

**Top 9% finish (272/3062)** in a 24-hour agentic AI hackathon — an agent that decides whether a user can safely afford a purchase, using a 90-day financial forecast.

`Python` · `Agentic AI` · `LLM Evidence Extraction` · `Deterministic Financial Engine` · `Computer Vision`

**The core idea:** the model never touches a number. It only interprets ambiguous evidence — does an income stream continue or has it ended, what does a payslip image actually say, what does a message in another language mean — and hands structured facts to a deterministic Python engine that reconstructs financial state, forecasts 90 days forward, and enforces every safety constraint. Backed by 125 automated tests and an independent output auditor.
