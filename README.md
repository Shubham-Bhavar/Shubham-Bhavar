🤖 Orchestrate 2026 — "Buy or Wait?"
Agentic financial decision system · Top 9% (272 / 3,062) · HackerRank Orchestrate 2026

An agent that decides whether a user can safely afford a purchase, based on a 90-day financial forecast — designed and built within a 24-hour hackathon.

Design principle — the model never touches a number. The LLM only interprets ambiguous evidence: whether an income stream continues or has ended, what a payslip image actually says, and what a message in another language means.
Deterministic financial engine. Structured facts are passed to a Python engine that reconstructs financial state, forecasts 90 days forward, and enforces every safety constraint.
Built for reliability. Backed by 125 automated tests and an independent output auditor.
Stack: Python Agentic AI LLM Evidence Extraction Deterministic Financial Engine Computer Vision
