### 🤖 Orchestrate 2026 — "Buy or Wait?"

**Agentic financial decision system** · Top 9% (272 / 3,062) at HackerRank Orchestrate 2026

An agent that decides whether a user can safely afford a purchase using a 90-day financial forecast — built in 24 hours.

| Layer | Responsibility |
|:---|:---|
| 🧠&nbsp;**LLM** | Interprets only ambiguous evidence — whether income continues, what a payslip image says, what a foreign-language message means. **Never touches a number.** |
| ⚙️&nbsp;**Engine** | Deterministic Python core that rebuilds financial state, forecasts 90 days forward, and enforces every safety constraint |
| ✅&nbsp;**Verification** | 125 automated tests and an independent output auditor |

`Python` · `Agentic AI` · `LLM Evidence Extraction` · `Deterministic Financial Engine` · `Computer Vision`
